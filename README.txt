Signature Studio website

This folder contains the static website files. The main page is index.html. It runs in the visitor’s browser and stores no name data on a server. Name-meaning source data and the optional WIPO spelling index are supplied in separate files beside the page. See DATA-LICENSES.md for source notes and attribution.

The optional WIPO spelling check loads a compact index only when the visitor requests it. Names typed into the app are checked locally in the browser and are not sent to a server. Google Fonts are loaded from Google Fonts when the page has internet access.
