Signature Studio website

This folder contains the static website files. The main page is index.html. It runs in the visitor’s browser and stores no name data on a server. Name-meaning data, multilingual name-form data, and the optional WIPO spelling index are supplied in separate files beside the page. See DATA-LICENSES.md for source notes and attribution.

A language data file loads when that language is selected. Names typed into the app stay in the browser and are not sent to a server. The optional WIPO spelling check loads a compact index only when the visitor requests it. Google Fonts are loaded from Google Fonts when the page has internet access.
